# 스마트 푸시 및 문자/카카오톡 알림 발송 시스템 구현 사양서 (무료 & 하이브리드 연동)

본 문서는 **스마트 푸시관리 (`/af/spush/lists`)** 및 **알림관리 (`/af/notification/lists`)** 화면에서 [알림전송] 버튼 클릭 시 동작하는 알림 발송 시스템의 아키텍처, 무료 구현 방안 및 구현 사양을 정리한 명세서입니다.

---

## 1. 시스템 개요 및 요구사항

- **대상 화면**:
  - 푸시알림관리: `/af/spush/lists/sn/3267` (`panel_spush_lists`)
  - 알림관리: `/af/notification/lists/sn/3267` (`panel_notification_lists`)
- **주요 기능**:
  - 관리자가 대상(전체/특정 학년/특정 강좌 수강생/학부모)을 선택하고 메시지를 작성하여 전송
  - 비용 부담 없이 운영 가능한 **100% 무료 스마트 웹 푸시(Web Push)** 기본 탑재
  - 실제 휴대전화 번호로 전송되는 **SMS/LMS 문자** 및 **카카오 알림톡** 듀얼 지원 (무료 테스트 Mock 모드 + 실제 API 연동 모드)

---

## 2. 발송 채널별 아키텍처 및 무료 구축 전략

```
[관리자 화면 (/af/spush/lists)]
   │
   ├── [알림전송 버튼 클릭] ➔ [발송 모달: 채널 및 대상자 선택]
   │
   ▼
[Express 백엔드 라우터: POST /api/af/spush/send]
   │
   ├─▶ [채널 1] 100% 무료 Web Push (VAPID / FCM)
   │     └─▶ 브라우저/스마트폰 상단 팝업 알림 (비용: 0원 평생 무료, 무제한)
   │
   ├─▶ [채널 2] 카카오 알림톡 (Kakao Alimtalk)
   │     ├─ [테스트 모드]: 화면 및 콘솔에 시뮬레이션 도착 팝업 (비용 0원)
   │     └─ [실제 모드]: 카카오 비즈메시지 API 연동
   │
   └─▶ [채널 3] SMS/LMS 통신사 문자 (Aligo / CoolSMS / NHN Cloud)
         ├─ [테스트 모드]: Mock 발송 및 가상 수신함 기록 (비용 0원)
         └─ [실제 모드]: 회원가입 무료 제공 크레딧(300~500건) 또는 API 키 연동
```

### 채널별 비교 요약

| 채널 | 기술 / 서비스 | 비용 | 특징 |
| :--- | :--- | :--- | :--- |
| **스마트 웹 푸시 (Web Push)** | Web-Push (VAPID) / Firebase (FCM) | **100% 영구 무료 (0원)** | • 앱스토어 설치 없이 학부모 웹 접속 시 [알림 수신 허용]만으로 스마트폰 상단바 알림 도착<br>• 건수 제한 없는 무제한 발송 |
| **카카오 알림톡** | Kakao Biz Message / Solapi | 가입 무료 혜택 / 건당 ~8원 | • 학부모 카카오톡 채널로 공식 템플릿 알림 수신<br>• 실패 시 SMS로 자동 전환 발송(Failover) |
| **SMS/LMS 문자** | 알리고(Aligo) / 솔라피(CoolSMS) | 가입 무료 크레딧 / 건당 ~8~25원 | • 90바이트 이하 단문(SMS), 90바이트 초과 장문(LMS) 지원<br>• 무료 개발자 모드(Mock) 내장으로 비용 없이 사전 검증 가능 |

## 3. 프론트엔드 모달 UI 사양 (`#modal_spush_send`)

### UI 구성요소
1. **발송 채널 탭 선택**:
   - `[🔔 스마트 웹 푸시 (무료)]` (기본값)
   - `[💬 카카오 알림톡]`
   - `[📱 SMS/LMS 문자]`
2. **수신 대상 선택**:
   - 대상 구분: `전체 수강생` / `특정 학년 (1~6학년)` / `특정 강좌 수강생` / `미설치자 전용`
   - 실시간 수신 대상자 수 카운팅 표시 (예: "총 128명 선택됨")
3. **메시지 입력 영역**:
   - 제목 입력 필드 (`push_title`)
   - 내용 텍스트에어리어 (`push_body`)
   - 실시간 바이트/글자 수 계산기 (90 Byte 기준 SMS ➔ LMS 자동 전환 표시)
   - **치환 변수 원클릭 삽입 버튼**: `#{학생명}`, `#{학교명}`, `#{강좌명}`, `#{강의실}`, `#{수강료}`
4. **발송 옵션**:
   - `즉시 발송` / `예약 발송 (날짜/시간 선택)`
   - `무료 테스트 발송 (관리자 번호로만 1건 발송)`

## 4. 백엔드 API 명세 및 구현 계획

### 4.1. 푸시/문자 발송 엔드포인트 (`POST /api/af/spush/send`)
- **Request Body**:
  ```json
  {
    "channel": "WEB_PUSH", // "WEB_PUSH" | "KAKAO" | "SMS"
    "targetFilter": {
      "type": "COURSE", // "ALL" | "GRADE" | "COURSE"
      "grade": "2",
      "courseId": "lec_101"
    },
    "title": "[늘봄학교] 방과후 수강료 납부 안내",
    "body": "#{학생명} 학생의 10월 방과후 수강료 납부 기간입니다.",
    "isMockTest": false,
    "scheduledAt": null
  }
  ```
- **Response**:
  ```json
  {
    "success": true,
    "message": "총 24명에게 스마트 푸시 알림이 성공적으로 전송되었습니다.",
    "stats": {
      "total": 24,
      "success": 24,
      "fail": 0
    },
    "historyId": "push_20261003_001"
  }
  ```

### 4.2. 푸시 구독 등록 엔드포인트 (`POST /api/af/spush/subscribe`)
- 학부모/학생 브라우저의 Web Push Subscription(Endpoint & Keys) 저장.

### 4.3. 발송 이력 조회 (`GET /api/af/spush/lists`)
- 발송 일시, 대상, 채널(푸시/카톡/문자), 성공/실패 건수, 열람율 리스트 반환.
