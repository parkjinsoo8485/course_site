[214] 지원금 대상자 삭제
[215] 漠杳
[216] 지원금 대상자로 등록되어 있어 수강자 가져오기를 통해 지원금 처리를 해 왔는데 지원금 대상자에서 탈락한 경우 기존에 지원금 처리한 내역을 모두 삭제해야 합니다.
[217] “지원금관리 > 수강자관리” 메뉴에서 검색란에 삭제할 학생 이름으로 검색합니다.
그러면 해당 학생의 지원금 처리 내역이 검색됩니다.
[218] 이 학생은 대상자가 아니므로 “대상자 관리”에서 해당 학생을 삭제하면 지원금 처리 내역도 함께 삭제됩니다.
[219] 漠杳
[220] “지원금관리 > 대상자관리” 메뉴에서 삭제할 학생 이름으로 검색하여 “삭제” 아이콘을 클릭합니다. 
그러면 해당 학생이 대상자 관리, 수강자 관리에 있는 데이터가 모두 삭제됩니다.

[222] 지원금 대상자 추가
[223] 漠杳
[224] 3월, 4월, 5월까지 수강자 가져오기를 통해 지원금 처리가 되었는데 새로운 지원금 대상자가 생겼다면 전체 가져오기를 초기화하여 다시 가져오기를 하지 않고 이 대상자를 대상자 관리에서 추가하고 “지원금관리 > 수강자관리” 메뉴에서 “수강자 등록”을 이용하여 개별 지원금 처리도 가능합니다.
[225] “지원금관리 > 대상자관리” 메뉴에서 “대상자 등록” 버튼을 클릭하여 새로운 지원금 대상자를 등록합니다.
[226] “지원금관리 > 수강자관리” 메뉴에서 월에서 “3월”을 선택하고 “수강자 등록” 버튼을 클릭합니다.
- 대상월 : 3월, “신청자 검색” 버튼을 클릭합니다.
- 월에서 “3월”을 선택하고 새로운 추가한 지원금 대상자 이름으로 검색합니다. 그러면 아래에 해당 학생이 수강한 과목이 출력되고 첫 번째 강좌 오른쪽에 있는 “이름”을 클릭합니다.
 漠杳     - - 위 신청자 검색까지 되었다면 맨 아래 “등록”을 클릭하여 개별 지원금을 등록합니다.
- 위와 같은 방법으로 3월, 4월, 5월까지 새로 추가한 지원금 대상자의 수강과목을 개별 지원금 처리해주세요.
[227] “수강자관리” 메뉴에서 새로 추가한 지원금 대상자 이름으로 검색합니다. 그러면 개별 지원금 처리한 내역이 출력됩니다.

[229] 지원금 처리 내역 수정
[230] 漠杳
[231] 수강자 가져오기로 자동 처리한 지원 내역을 수동으로 조정해 줄 수 있습니다. 
이렇게 수동으로 조정한 경우 다시 수강자 가져오기를 하면 안됩니다. 수강자 가져오기를 하면 순차적으로 다시 지원금을 재정산하므로 위에서 수작업으로 조정한 것이 모두 변경되어 버립니다.
[232] 따라서 수강자 가져오기를 통해 지원금을 처리하고 징수 결재를 올렸다면 전체 가져오기를 다시 하지 않고 위 개별 처리 방법을 이용해 개별 처리해주세요.
[233] “지원금관리 > 수강자관리” 메뉴에서 “수강자 가져오기”를 통해 지원금을 자동 정산한 결과를 수동으로 조정하고 싶을 때 아래와 같은 방법으로 수정이 가능합니다.
[234] “지원금관리 > 수강자관리” 메뉴에서 수정할 학생 이름으로 검색합니다.
[235] 지원금을 수정할 학생의 강좌명 옆에 “수정” 버튼을 클릭합니다.
[236] 漠杳
[237] 자유수강권 또는 추가 지원금의 “수강료, 수용비, 교재비, 재료비”를 수정하고 맨아래 “수정” 버튼을 클릭합니다.
그러면 지원금 정산 내역이 수정됩니다. 이렇게 수동으로 지원금 처리 내역을 변경한 경우 다시 “수강자 가져오기”를 하면 안됩니다.
