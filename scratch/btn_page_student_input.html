학생관리
일괄입력

표시가 있는 항목은 반드시 입력해야 합니다.

데이터 형식  
 
엑셀 파일   (일괄입력 샘플 : stuInput.xlsx stuInput2.xlsx)
한셀로 만들어진 엑셀파일은 변환 후 사용할 수 있습니다.
기존 데이터

[주의] 기존 데이터를 삭제하거나, 학적이 수정되는 경우 이용 중인 서비스(방과후학교, 자유학기제, 우유신청 등)에 등록된 자료에 영향을 줄 수 있으므로 충분히 검토 후 처리하시기 바랍니다. [관련 도움말 보기]
신입생
임시학년
(신입생이 사용할 임시학년 선택, 추가 학년은 "학생관리 > 기본설정"에서 설정 바랍니다.)
초기 비밀번호   (4~15자 이내의 영문 또는 숫자)
※ 기존에 등록된 학생인 경우 비밀번호가 변경됩니다. 비밀번호를 변경하지 않는 경우에는 입력하지 마세요.
※ 엑셀파일 안에 직접 입력되어 있지 않은 경우에만 사용됩니다.
참고사항
※ 샘플파일(기본) 참고사항
  - 첫 번째 줄의 내용은 변경할 수 없습니다.
  - 학년 : 필수 항목입니다.
  - 학과 : 학과 설정이 되어 있는 경우에만 필수 항목입니다.
  - 반 : 필수 항목입니다.
  - 번호 : 필수 항목입니다.
  - 이름 : 필수 항목입니다.
  - 성별 : 회원필드설정에 'Yes'로 되어 있는 경우에만 필수 항목입니다.
  - 비밀번호 : 선택 항목입니다.
  - 휴대폰 : 선택 항목입니다.
  - 보호자 성명 : 선택 항목입니다.
  - 보호자 연락처 : 선택 항목입니다.

○ 나이스에서 명렬표 출력
  - 학적 > 기본학적관리 > 전체명렬표 출력

○ 에듀파인에서 명렬표 출력
  - 수입관리 > 수납자관리 > 학생진급관리 > 엑셀일괄처리 > 조회 > 엑셀서식다운
※ 샘플파일(신입생) 참고사항
  - 첫 번째 줄의 내용은 변경할 수 없습니다.
  - 이름 : 필수 항목입니다.
  - 생년월일 : 임시반, 번호를 자동으로 지정하는 용도로 사용됩니다.
  - 비밀번호 : 선택 항목입니다.
  - 성별 : 회원필드설정에 'Yes'로 되어 있는 경우에만 필수 항목입니다.

○ 등록만 되고 수정은 처리되지 않습니다.
○ 생년월일과 이름이 동일한 신입생인 경우 별도 등록 및 안내가 필요합니다.

  • 학과를 입력하는 경우 학교환경설정 > 학과설정 > 코드명과 일치하도록 입력해 주세요.
  • 비밀번호는 4~15자 이내의 영문 또는 숫자로 입력해 주세요.
  • 학년, 학과, 반, 번호, 이름이 같은 기존 데이터는 수정(성별, 비밀번호, 휴대폰, 보호자 성명, 보호자 연락처)됩니다.
    (비밀번호, 휴대폰, 보호자 성명, 보호자 연락처는 내용이 입력된 경우에만 수정됩니다.)
